# 沖繩親子自由行 2026｜第四版正式上線版

這個資料夾可直接部署到 GitHub Pages。

## GitHub Pages 上線
1. 在 GitHub 建立新的 Repository，例如 `okinawa-trip`
2. 把本 ZIP 解壓後「資料夾內的所有檔案」上傳到 Repository 根目錄
3. GitHub → Settings → Pages
4. Source 選 `Deploy from a branch`
5. Branch 選 `main`，Folder 選 `/ (root)`
6. 儲存後等待 GitHub 產生網站網址

## 手機使用
- iPhone：Safari → 分享 → 加入主畫面
- Android：Chrome 可使用安裝 App / 加到主畫面

## 正式版功能
- 旅行前倒數／旅行中自動顯示 Day 1–6／旅行後回顧模式
- 每日行程與 Google Maps 導航
- 收藏、購物清單、行李清單、每日備忘
- 花費記帳、分類小計、日幣換算
- 01–60 頁手冊與放大閱讀器
- PWA 手機主畫面圖示
- 離線快取
- 分享網址
- 緊急資訊

## 資料保存
收藏、清單、花費、匯率與每日備忘使用瀏覽器 localStorage 儲存。
若清除該網站的瀏覽器資料，紀錄也會被清除。
